# IDGAF CAMERA (`v0.7.7.1` — SAVIOR Stable Milestone)

*A love letter to indie filmmakers — by Savior San.*

Free, open Android cinema camera powered by the **Savior Cinema Engine** (native **Kotlin + Camera2 + OpenGL ES 2.0**) by **Studio Mogli** ([www.studiomogli.com](https://www.studiomogli.com)).

## What's New in `v0.7.7.1` (SAVIOR Stable)
- **Live Output Monitor (`MON → OUT` — Draggable PiP Clean Program Feed):**
  - Renders a dedicated 3rd hardware GPU pass showing the **exact video being saved to your MP4**: zero scopes/peaking/zebras/false-color/split-wipe, true `16:9` or vertical `9:16` output framing, and real **Time-Lapse / Low-FPS cadence preview** (pulses on every captured frame so you always know if Time-Lapse is armed or rolling).
  - Drag anywhere on screen; zero GPU cost when toggled OFF.
- **Quick Cinema ISO Presets + Custom `✎` Input:**
  - 1-tap ISO preset strip (`50 | 100 | 200 | 400 | 800 | 1600 | 3200`, dynamically matched to each lens's real hardware ISO range) right inside the ISO drawer alongside the log slider and `✎` exact-value button.
- **Production-Grade Clean UI:** Removed all internal developer/plug-in strings from user-facing menus; marked **`v0.7.7.1 • SAVIOR Stable`** as the frozen SAVIOR Core milestone ready for isolated Era camera modules.
