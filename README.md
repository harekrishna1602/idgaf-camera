# IDGAF CAMERA (`v0.6.2` — Pre-Emulation Core Polish)

Free, open, community-built Android cinema camera built on native **Kotlin + Camera2 API** by **Studio Mogli** ([www.studiomogli.com](https://www.studiomogli.com)).

## What's New in `v0.6.2`
- **Studio Mogli Credits & About (`IDGAF CAM`):** Tap `IDGAF CAM` in the top-left HUD for app version, `© 2026 Studio Mogli` copyright, clickable `www.studiomogli.com`, and a manual **Check for Updates** button.
- **OIS / EIS Stabilization Toggle (`PRO → STAB`):** Hardware video stabilization toggle for handheld vs. tripod/gimbal shooting.
- **Hardware Torch Toggle (`PRO → TORCH`):** Continuous LED video light on back lenses—and automatically enabled on front cameras if the device has front LED flash hardware.
- **Live Battery % & Free Storage (GB):** Real-time monospace telemetry in the top HUD bar with low-battery/low-storage color warnings.
