# IDGAF CAMERA (`v0.3.0` — Phase 3: Cinema Monitoring Overlays)

Free, open, community-built Android cinema camera built on native **Kotlin + Camera2 API** by **Studio Mogli**.

## What's New in Phase 3 (`v0.3.0`)
- **Cinema Monitoring Toolbar (`MON`):** 1-tap toggle for professional on-screen monitoring tools:
  - **Focus Peaking (`PEAK`):** Real-time neon-green edge highlighting so you nail manual focus & A/B rack pulls.
  - **Overexposure Zebras (`ZEBRA`):** Diagonal red warning stripes on clipped highlights (`>= 92% IRE`).
  - **Aspect Ratio Frame Guides (`FRAME`):** Matte overlays for `2.39:1` CinemaScope, `16:9`, and `9:16` Vertical/Reels.
  - **Rule of Thirds + Crosshair (`GRID`):** Clean composition grid with Safety Orange center reticle.
  - **Live Luma Histogram (`HIST`):** Compact cinema exposure scope in the top-left corner.
- **Fixed REC Shutter Morph:** Inner red square now smoothly scales down (`0.54x`) inside the outer white circle when recording.
